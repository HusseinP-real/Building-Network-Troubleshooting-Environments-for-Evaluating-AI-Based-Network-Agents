[GROUND-TRUTH]
Fault location: dhcp1
Fault type: DHCP incorrect default-router option
Root cause, expected symptoms and controls: Added dhcp1 advertises unused 192.168.0.254 instead of the original super_spine_router_0 gateway 192.168.0.1. Real lease renewal installs the wrong default route while preserving original client_0 IP 192.168.0.2. Local gateway and another external client remain healthy. Correct the DHCP router option and renew client_0, rather than patching only its route.

[FIX]
On dhcp1, execute:
set -eu
sed -i 's/option:router,192.168.0.254$/option:router,192.168.0.1/' /etc/dnsmasq.d/clos.conf
sh /opt/soft3888/dns-control restart
Renew client_0 afterwards: sh /opt/soft3888/dhcp-client renew
